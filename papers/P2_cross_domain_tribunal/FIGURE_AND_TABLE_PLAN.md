# P2 Figure and Table Plan

## Main figures

### Figure 1 — The intervention tribunal

A left-to-right adjudication pipeline:

1. freeze jurisdiction and semantic signature;
2. verify baseline sufficiency;
3. substitute components/parameters/substrate;
4. ablate critical relations;
5. rewire while preserving cardinality where possible;
6. test transport;
7. enumerate minimal carriers;
8. output `POSITIVE`, `NEGATIVE`, `ABSTAIN`, or `NO_UNIQUE_MINIMAL_CARRIER`.

The figure must make clear that no weighted average can compensate for a failed critical gate.

### Figure 2 — Cross-domain carrier atlas

Ten rows, grouped by carrier type:

- dynamical closure: oscillation, RPA, synchronization, Turing;
- informational closure: error correction, proofreading, consensus;
- state-memory closure: bistability;
- topological closure: edge transport;
- chemical closure: minimal RAF.

Columns: signature, carrier, substitution, ablation, rewiring, transport, minimality, evidence class.

### Figure 3 — Relation-first intervention asymmetry

Two panels:

- same component inventory, altered relation, lost signature;
- changed components/substrate, preserved relation class, preserved signature.

Use one biological, one computational and one physical example in each panel.

### Figure 4 — Designed adversarial benchmark

Panels:

- strict confusion matrix;
- precision and FDR under strict/moderate/weak semantic profiles;
- missing-evidence coverage under conservative abstention.

### Figure 5 — Naturalistic mechanism–decoy pairs

Five paired columns:

- proofreading / equilibrium recognition;
- Turing / instructed stripe;
- mutual synchronization / common forcing;
- topological protection / defect localization;
- RAF closure / open catalytic chain.

A final branch shows two mixed-mechanism cases ending in `ABSTAIN`.

### Figure 6 — Refinement order

A partial-order diagram with homeostasis above robust perfect adaptation, and explicit room for future equivalence, refinement and incomparability relations among UMI classes.
