# HGMF-HG35 — Núcleo formal

## 1. Magnetic interval null

Sea h_n el exchange-bias observado en loop n y Δ_n la resolución field-step reportada por el source loader.

El source mechanism autoriza el structural summary null:

μ_1 ∈ R\{0},
μ_n = 0, n=2,...,5.

Sin interpretar Δ_n como desviación estándar, usamos set membership:

μ_n ∈ [h_n-Δ_n, h_n+Δ_n].

El null es compatible si 0 queda fuera del intervalo del loop 1 y dentro de los intervalos de los loops 2–5.

Esto es una afirmación cuantitativa de resolución, no un p-value.

## 2. Binek diagnostic

Como standard exchange-bias training comparator:

H_(n+1)-H_n = -Γ (H_n-H_inf)^3.

Se ajusta sólo como diagnóstico secundario. El paper FGT/CrSBr atribuye el one-shot disappearance a una metastable-state transition, no a Binek relaxation.

## 3. Bethe network

Primary desorption:

Qp(q)=1-y^z,

y=(1-q)+q y^(z-1).

Scanning desorption with initial unfilled fraction Q+:

alpha(q,Q+)=1-y^z,

y=(1-q)+q(1-Q+) y^(z-1),

Q-(q,Q+) = Q+ + (1-Q+) alpha(q,Q+).

Bethe threshold:

q_c = 1/(z-1).

Published Vycor estimates z=6.6, 7.2 imply q_c in [0.16129,0.17857].

## 4. Observation bridge

Measured adsorption V(p) maps to unfilled-pore fraction via:

Q(p) = [Vc(p)-V(p)]/[Vc(p)-Vs(p)].

Therefore a complete network likelihood requires Vs(p), Vc(p), q(p), and a measurement/error model.

Without those objects, a topology model is not yet an observation likelihood.

The existence of an unresolved standard network family on the exact Brown benchmark blocks any current claim that HG34 RPM residuals are beyond standard.
