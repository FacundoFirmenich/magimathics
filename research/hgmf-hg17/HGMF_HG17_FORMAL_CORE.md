# HGMF‑HG17 — Núcleo formal

## Context groupoid

\[
\Omega_{\alpha\beta\gamma}
=T_{\alpha\leftarrow\gamma}T_{\gamma\leftarrow\beta}T_{\beta\leftarrow\alpha}.
\]

## Gauge covariance

\[
T'_{\beta\leftarrow\alpha}=G_\beta T_{\beta\leftarrow\alpha}G_\alpha^{-1},
\qquad
\Omega'=G_\alpha\Omega G_\alpha^{-1}.
\]

Only conjugacy data are gauge invariant in the non-Abelian case.

## Flatness–coboundary theorem

On a connected pair groupoid with exact inverses:

\[
\Omega_{\alpha\beta\gamma}=I\ \forall\alpha,\beta,\gamma
\iff
\exists G_\alpha:\ T_{\beta\leftarrow\alpha}=G_\beta G_\alpha^{-1}.
\]

## Projective transport

\[
U_gU_h=\omega(g,h)U_{gh},
\]

\[
\omega(g,h)\omega(gh,k)=\omega(h,k)\omega(g,hk).
\]

Changing section modifies \(\omega\) by a coboundary. The cohomology class is projectively invariant.

## Vector–ray–channel stratification

If \(\Omega=e^{i\chi}I\), the vector lift is nontrivial but the projective and density-channel actions are identity. Noncentral \(\Omega\) is operationally visible but may remain standard quantum mechanics.

## Diagnostics

\[
J_{nc}=\sqrt{2-2|\operatorname{Tr}\Omega|/d},
\qquad
J_{ch}=\sqrt{1-|\operatorname{Tr}\Omega|^2/d^2}.
\]

## Discrete Bianchi

For an Abelian edge connection \(\theta\), face curvature is \(\omega=\delta\theta\), hence \(\delta\omega=0\).

## Scale no-go

A holonomy class is dimensionless. A curvature density requires a physical area form, units, logarithm branch and coupling. No energy/time/length scale follows from cocycle data alone.

## Attribution boundary

A nonzero cocycle diagnoses path dependence or nonfunctoriality in the declared transport. It does not identify origin. Standard controls, frame imperfections and process tensors can reproduce it.
