# No cross-promotion contract

1. A result proved in one repository has authority only within its declared model and jurisdiction.
2. A PASS in BQ, HM, ODT or foundations does not update RGΦ mainline.
3. The Magimatics centrum coordinates the portfolio but does not collapse distinct manuscripts into a superpaper.
4. Negative results, abstentions, failed replications and resource blockers remain citable evidence.
5. Each repository owns a separate claim/evidence matrix, version history, release line and Zenodo DOI family.
6. Shared code must be vendored by immutable release/commit reference or moved to an explicitly versioned methods repository; it must not be silently copied.
