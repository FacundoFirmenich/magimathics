# Minimal Invariant Relational Units Across Five System Functions
## Draft manuscript seed

### Abstract

A general theory of systems requires an operational criterion for identifying units whose identity resides in relations rather than component inventory. We evaluate a preregistered tribunal based on substitution, rewiring, ablation, cross-substrate transport and jurisdictional minimality. Previous applications identified carriers for sustained oscillation and robust perfect adaptation. Here we adjudicate four further candidates. In Hamming single-error correction, the unit is the three-relation syndrome partition whose seven nonzero columns uniquely identify error positions. In bistable memory, it is regenerative feedback closed by saturation and write coupling. In distributed consensus safety, it is quorum intersection coupled to persistent single-vote memory. Negative-feedback homeostasis also passes the tribunal but is not independent: it forms a parent class whose internal-model refinement is robust perfect adaptation. Across domains, the common object is an inclusion-minimal relational equivalence class whose semantic signature survives admissible substitution and transport but disappears under critical rewiring or ablation. We call this object a minimal invariant relational unit (UMI). The work makes no ontological or multifractal claim and does not claim discovery of the established coding, feedback, memory or consensus principles used as test cases.
