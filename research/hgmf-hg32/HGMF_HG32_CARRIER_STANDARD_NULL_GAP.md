# HGMF‑HG32 — Gap de modelos estándar específicos del carrier

## 1. Auditoría del tribunal previo

UMI‑10 comparó operadores de memoria generales: memoryless, branch, fading, RPM relays y finite stack.

Ese tribunal fue apropiado para la pregunta semántica de historia/memoria. No constituye todavía un tribunal físico completo contra los modelos estándar de cada carrier.

## 2. Magnetismo

La literatura de histéresis magnética trata como familias centrales, entre otras:

- Preisach y generalized Preisach;
- Jiles–Atherton / Duhem;
- Play / Prandtl–Ishlinskii;
- Stoner–Wohlfarth en jurisdicciones microestructurales apropiadas;
- extensiones dinámicas/rate-dependent cuando la tasa de excitación forma parte del experimento.

Para minor loops y path dependence, Preisach/generalized Preisach y Jiles–Atherton son competidores obligatorios salvo una exclusión material/experimental documentada.

## 3. Adsorción

Para hysteresis de physisorption en sistemas porosos, los competidores estándar dependen del adsorbato/material, pero el registry debe considerar:

- classical DFT / lattice-gas;
- NLDFT / QSDFT cuando el kernel material–pore corresponde;
- capillary condensation;
- pore blocking;
- cavitation;
- pore-network/interconnectivity models.

Langmuir/BET pueden servir como baselines reversibles, pero no constituyen por sí solos una explicación completa de hysteresis.

## 4. Metadata pendiente

El corpus persistido identifica NIST runs con pressure, adsorption y temperature, pero el cierre canónico actual no contiene suficiente metadata de material/adsorbato/pore geometry para congelar qué DFT/pore-network family exacta corresponde.

Asimismo, los cuatro loops magnéticos no fijan aquí una jurisdicción material suficiente para elegir entre todas las variantes físicas.
