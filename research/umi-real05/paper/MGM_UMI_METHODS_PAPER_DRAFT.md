# Minimal Invariant Relational Units
## A cross-domain intervention tribunal from error correction to topological transport

### Abstract

A general theory of systems requires an operational criterion for units whose identity resides in relations rather than component inventory. We evaluate a frozen tribunal based on semantic-signature specification, component substitution, relational rewiring, critical ablation, cross-substrate transport and jurisdictional minimality. Earlier cases covered oscillation, robust adaptation, error correction, memory and consensus. A literature-naturalistic evidence-blind benchmark adds kinetic proofreading, Turing pattern formation, mutual synchronization, topological edge transport and autocatalytic closure, paired with close decoys and mixed-mechanism hybrids. The tribunal identifies all five established relational carriers, rejects all five decoys and abstains on two hybrids. Across cases, the common object is not a graph motif or material module but an inclusion-minimal mechanism class preserving a preregistered semantic signature. We call this object a minimal invariant relational unit (UMI).

### Central definition

A UMI is an inclusion-minimal relational mechanism class that preserves a frozen semantic signature under admissible substitution and transport, and loses that signature under critical ablation or rewiring.

### Mechanism classes added in REAL‑05

- kinetic proofreading;
- Turing finite-wave-number instability;
- mutual synchronization;
- topological bulk–boundary protection;
- minimal RAF autocatalytic closure.

### Methodological result

The same tribunal separates mechanism from phenotype: equilibrium recognition is not proofreading, an instructed stripe is not a Turing instability, common-drive alignment is not mutual synchronization, a defect mode is not topological protection, and an open catalytic chain is not an autocatalytic closure.
