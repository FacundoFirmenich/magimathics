# HGMF‑HG34 — Núcleo formal de falsadores estructurales

HG33 demostró que un outer Preisach span puede saturar un loop simple. HG34 cambia el objeto de curve fit a cross-history invariants.

## Return-point memory

Para una entrada escalar rate-independent con RPM, si una trayectoria vuelve al reversal point no borrado antes de una nueva reversión, el estado debe retornar. Operacionalmente:

x(t2)=x(t1), S(t2)=S(t1) => y(t2)=y(t1).

El auditor HG34 sólo considera cierres reversal a -> reversal b -> retorno a antes de cualquier nueva reversión. No clasifica como RPM cualquier par de extrema con presión parecida.

## Wiping-out y branch rejoin

Cuando una excursión cerrada se borra al recuperar un reversal point ancestral, la trayectoria debe reingresar en la rama ancestral. Hace falta observar también esa rama counterfactual en el mismo intervalo para testearla; si no existe, el output es ABSTAIN.

## Congruency / Everett

Minor loops con los mismos reversal endpoints imponen relaciones cross-history. Comparar histories repetidas evita que un basis single-path vuelva a ajustarse de manera independiente.

## Magnetic structural null

Para FGT/CrSBr, el source model predice una transición irreversible de clase de estado: preset metastable state -> trained domain state. El primer loop visita estados metastables que los siguientes ya no visitan.

Predicciones:
- |H_EB| máximo en loop 1;
- switching-width asymmetry máxima en loop 1;
- reducción fuerte de exchange bias tras training;
- loops posteriores gradual/gradual.

## Claim boundary

Compatibilidad estructural con un null estándar basta para mantener ese null vivo. Mismatch estructural no autoriza beyond-standard sin un modelo de incertidumbre y multiplicidad confirmatoria.
