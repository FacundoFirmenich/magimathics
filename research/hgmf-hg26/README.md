## Resultado rector

HG26 convierte cada unidad experimental en un objeto auditable. Distingue cinco capas que no pueden colapsarse:

1. identidad de bytes;
2. procedencia;
3. admisibilidad experimental;
4. completitud causal;
5. identificabilidad inferencial.

Un SHA‑256 prueba identidad de contenido respecto de un digest; no prueba calibración, reset, historia, ausencia de confounding ni validez del análisis.
