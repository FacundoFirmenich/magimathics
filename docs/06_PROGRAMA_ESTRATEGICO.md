# Programa estratégico posterior al primer cierre conformacional

## 1. Principio rector

No avanzar por acumulación conceptual. Cada frontera debe cerrar una deuda:

1. **definicional** — qué significa exactamente;
2. **formal** — qué se sigue de las premisas;
3. **identificatoria** — qué sistema real satisface la definición;
4. **externa** — qué sobrevive réplica, revisión y literatura.

## 2. Frente A — UMI como unidad relacional de sistemas

### Pregunta

¿Existe una clase de sistemas heterogéneos en los que una misma firma relacional mínima:

- sobreviva sustitución de sustrato;
- sobreviva cambio de escala;
- se pierda por recableado;
- se pierda por ablación relacional;
- sea composable hacia arriba?

### Diseño

Tres dominios:

1. computacional;
2. biológico/fisiológico;
3. social/organizacional.

Para cada uno:

- fijar jurisdicción `J`;
- enumerar carriers;
- construir firma `Σ_J`;
- hallar carriers inclusion-minimal;
- comparar causal states, bisimulation, minimal realization y closure of constraints;
- ejecutar sustitución, recableado y ablación.

### Salidas

```text
PASS_CROSS_DOMAIN_UMI
PASS_DOMAIN_LOCAL_ONLY
NO_UNIQUE_MINIMAL_CARRIER
FAIL_RELATIONAL_IDENTITY
```

## 11. Próximo gate recomendado

El siguiente gate principal debe ser **UMI‑REAL‑01**:

1. seleccionar tres sistemas heterogéneos;
2. preregistrar task/jurisdiction;
3. encontrar carriers mínimos;
4. probar sustitución, recableado, ablación y transporte;
5. comparar con causal states/bisimulation/minimal realization;
6. auditar multifractalidad triaxial;
7. emitir `PASS`, `FAIL`, `NO_UNIQUE_MINIMAL_CARRIER` o `HOLD`.

Es el gate más corto hacia una contribución top-tier publicable sin exigir primero cerrar toda la física pregeométrica.

## 12. Criterio de cierre top-tier

Un siguiente gran cierre requiere:

- teorema no trivial;
- contraejemplo/no-go;
- identificación empírica o benchmark;
- claim ledger;
- código;
- checker independiente;
- control de literatura;
- frontera de autoridad.

No se usará “top-tier-0” para una arquitectura exclusivamente conceptual sin tribunal material.
